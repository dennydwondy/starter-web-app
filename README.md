# Starter Web App

A minimal Express.js starter web app that serves a static page and a tiny JSON API.

Features:
- Static site served from `public/`
- API route: `GET /api/hello`
- Health check: `GET /health`

Quick start

1. Install dependencies

```bash
npm install
```

2. Run in development (requires nodemon, included as devDependency):

```bash
npm run dev
```

3. Or run normally:

```bash
npm start
```

The app will be available at http://localhost:3000
